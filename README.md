# ms-pos-probe
The POS‑PROBE project delivers an AI‑powered extension to an existing POS and ecommerce system, designed to optimize inventory management and safeguard transactions. It introduces predictive restocking through time‑series forecasting to reduce spoilage, stockouts and outlier detection to flag fraudulent or abnormal sales behavior in real time
